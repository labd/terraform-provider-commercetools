## v1.23.0 - 2026-10-26
### Added
* New resource `commercetools_insights_configuration` to manage the Platform Insights configuration of a Project, exporting logs and metrics to NewRelic, Dynatrace, Datadog or an OTLP provider
* Enhance `commercetools_api_extension` to support the `dependencies`, `expansion_paths` and `additional_context` fields. Dependencies can be referenced by key or by id.
* Add `saved_to_line_item` to the `attribute` block of `commercetools_product_type`, controlling whether the attribute value is copied onto Line Items (defaults to `true`, as in the API)
### Fixed
* Fix `commercetools_channel` reading `address.additional_street_info` from the API's `additionalAddressInfo` field instead of `additionalStreetInfo`
* `commercetools_api_extension` now passes any `resource_type_id` through to commercetools, adding support for `recurring-order`, `approval-rule`, `payment-method` and `customer-group` triggers. Previously unlisted types were sent as an empty string
### Security
* Update google.golang.org/grpc to v1.83.1, golang.org/x/crypto to v0.52.0 and golang.org/x/net to v0.55.0 to resolve security advisories
* Update google.golang.org/grpc to v1.83.2 to resolve GHSA-2v4p-qf9q-27wj
### Dependency
* Update to Go 1.27
* Update all Go dependencies
